## A little about me

**Italian roots, Dublin chapter.** I'm a software engineer at Microsoft, working on **Copilot Studio**, with a focus on autonomous agents, agent activity, and testing experiences.

My background is in **Computer Engineering**, with an MSc focused on **AI Intelligent Systems** from the University of Florence. That curiosity runs through my projects: machine learning, computer graphics, robotics, concurrent systems, and small tools that make everyday life easier.

Outside the code editor, there's music, a different perspective from a drone, and the occasional robot trying very hard not to fall over. **Piano piano** — one experiment, one lesson, one commit at a time.

## On the workbench: MediMemo

**A happier medicine cabinet.** [MediMemo](https://github.com/edoardorex/medimemo) is a small, local-first web app for tracking medicine expiry dates, scanning package codes with a camera, and opening prefilled Google Calendar reminders.

No signup. No backend. Your cabinet stays in your browser, and you review and save any Calendar event yourself. **Meno stress, more peace of mind.**

[Try MediMemo →](https://edoardorex.github.io/medimemo/) · [Explore the code →](https://github.com/edoardorex/medimemo)
